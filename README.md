Deskripsi Program
Adventure Camp merupakan program berbasis console yang dibuat menggunakan bahasa pemrograman C untuk membantu proses penyewaan peralatan camping.

Program ini menyediakan fitur:
1. Menampilkan daftar peralatan dan harga sewa.
2. Melakukan penyewaan peralatan.
3. Menghitung subtotal, diskon, dan total pembayaran secara otomatis.
4. Menampilkan struk penyewaan.
5. Menampilkan riwayat transaksi dan total pendapatan.

Daftar Peralatan
- Tenda Kapasitas 4 Orang: Rp50.000/hari
- Sleeping Bag: Rp15.000/hari
- Kompor Portable: Rp20.000/hari
- Matras Camping: Rp10.000/hari
- Lampu Camping: Rp12.000/hari

Ketentuan Diskon
- Penyewaan 1–2 hari: 0%
- Penyewaan 3–4 hari: 10%
- Penyewaan 5 hari atau lebih: 15%

Teknologi
- Bahasa pemrograman: C
- IDE: Code::Blocks
